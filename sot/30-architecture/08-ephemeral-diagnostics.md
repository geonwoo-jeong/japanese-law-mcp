# SOT-ARCH-008: 一時的な診断

- 状態: 有効

## 規定

実行時の診断は、その場の処理状態を確認するために明示的に有効化した一時出力として提供し、リクエストから受け取った情報を含めない。

診断を有効にした場合は、transport にかかわらず `tools/call` を 1 回処理するごとに、処理完了後の標準エラーへ UTF-8 の JSON object を 1 行で出力する。診断を無効にした場合、および `tools/call` 以外の MCP method では出力しない。

## 診断項目

JSON object の項目は次の三つに限る。

| 項目 | 必須 | 値 |
|---|---:|---|
| `component` | はい | 固定値 `mcp` |
| `operation` | はい | 処理した登録済み公開ツール名。ツールを安全に特定できない場合は固定値 `tools/call` |
| `errorCode` | 失敗時のみ | ツールが返した公開エラーコード。公開コードを安全に特定できない protocol error または内部失敗は固定値 `internal_error` |

正常終了では `errorCode` を省略する。検索語、法令識別子、法令本文、ツールの入力と出力、認証情報、セッション情報、外部レスポンス、時刻、処理時間および内部スタックトレースは含めない。

同時に複数の処理が完了しても JSON 行を混在させない。診断の書込み失敗は、MCP の結果、protocol error および server の継続可否を変更しない。アプリケーションは診断を保存しない。

## 確認

診断を有効にした正常系、公開エラー、未知ツール、同時実行および書込み失敗を実行し、標準エラーへ規定どおりの JSON 行だけが出力されること、禁止した情報が現れないこと、および MCP の結果が診断の成否で変わらないことを確認する。診断を無効にした場合と `tools/call` 以外の method で出力しないことも確認する。
