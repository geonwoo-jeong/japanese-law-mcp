# SOT-ARCH-017: 採用可能な能力群

- 状態: 有効

## 規定

アプリケーションは、法令コアと選択型法情報拡張パックに必要な意味だけを能力群として所有し、利用目的と情報の意味ごとに型を定めた小さな情報源ポートへ分ける。

## 能力群

採用を検討できる共通能力の名前空間を次に限定する。

| 能力群 | 能力 ID の名前空間 | 保持する意味 | 利用する範囲 |
|---|---|---|---|
| 法令 | `law.*` | 法令、リビジョン、条文および法令更新 | 法令コア、税務、労働 |
| 裁判例 | `judicial-decision.*` | 裁判所、事件、裁判、判示事項および裁判要旨 | 裁判例、税務、労働 |
| 国会会議録 | `parliament.*` | 国会、会議、議事および発言 | 立法過程 |
| 議案 | `bill.*` | 議案、提出、審議経過および公表文書 | 立法過程 |
| 行政解釈資料 | `administrative-guidance.*` | 通達、通知、指針その他の行政機関による解釈または取扱い | 税務、労働 |
| 行政裁決 | `administrative-decision.*` | 行政不服申立てに対する公表裁決および裁決要旨 | 税務、労働 |

この表は、採用を検討できる能力群の語彙と意味の境界だけを定める。個別の能力 ID、メジャーバージョン、入力、出力、欠落時の扱い、継続取得、エラー、binding または公開 MCP ツールを採用したことを表さない。それらは各機能を公開する前に、能力別 SOT で定義する。

税務と労働は独自の汎用能力名前空間を持たず、法令、裁判例、行政解釈資料または行政裁決のうち、意味が一致する能力を組み合わせる。分野による絞り込みは、個別能力の型付き条件または route として定義し、同じ意味の情報へ別名のモデルを作らない。

選択型拡張パックが法令コアと同じ能力 ID を使う場合でも、その pack を選択していない無設定起動で既定 route を共有しない。pack-aware な route 選択または有効化方法を定義する後継 SOT を採用するまでは、同じ能力 ID を持つ拡張 provider を組込み既定値へ参加させず、既存 core route と独立した公開機能または provider-specific capability として扱う。

一つのプロバイダーは、公式仕様と個別能力 SOT の意味が一致する情報源ポートだけを実装する。未対応の能力を空の結果、既定値または推測値で実装しない。

既存 MCP ツール名、外部 API の操作名、および似た語を持つ文書は、自動的に同じ共通能力へ属さない。公開ツールと能力別ポートの対応は mapping SOT で明示する。

## 禁止する形

- `Execute(operation, map)` のように操作名と無型の値だけを受けるポート
- 全ての情報を `Search`、`Get`、`date`、`status` または `content` だけへ縮約するポート
- プロバイダー固有 DTO、HTML 要素、XML 要素または PDF の内部表現をアプリケーションへ公開するポート
- `SOT-PROD-009` の対象外情報を、プロバイダーが取得できるという理由だけで能力群へ追加すること

## 確認

個別能力を登録する前に、その ID と版に対応する有効な能力別 SOT が存在し、同じ binding を宣言する全プロバイダーが同じ型付き契約テストに合格することを確認する。
