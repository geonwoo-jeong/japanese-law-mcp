# SOT-ARCH-020: 採用済みユースケース境界

- 状態: 有効

## 規定

ユースケース境界は、有効な利用シナリオ SOT が採用した処理を実行し、MCP の通信形式、特定の外部 API 形式およびプロバイダー固有の表現には依存しない。

## 意味

この境界は、法令コアの法令名検索、法令本文検索、法令本文取得、条文取得、更新一覧取得および改正履歴一覧取得に加え、有効化された選択型拡張パックの採用済みシナリオを実行する。

ユースケースは共通情報モデルを使って処理を組み立て、能力別の型付き情報源ポートを呼び出す。MCP 固有のリクエスト型、HTTP リクエスト型、HTML 要素、外部 API のレスポンス型およびプロバイダー固有 DTO を判断へ持ち込まない。

拡張パックが無効な場合も、そのユースケース実装またはプロバイダーの登録だけを理由に公開ツールを追加しない。公開面の選択は `SOT-ARCH-019` に従う。

## 確認

各利用シナリオのテストを実際の MCP 接続や外部ネットワークなしで実行し、拡張パックの有効化とプロバイダーの選択を別々に検証できることを確認する。
