# SOT-ARCH-007: 依存方向

- 状態: 有効

## 規定

ソースコードの依存は、トランスポートと MCP ツールからユースケースへ、情報源アダプターからユースケースが所有する情報源ポートと情報モデルへ向ける。ユースケースと情報モデルから、外側の具象実装へ向かう依存は作らない。

## 許可する関係

- 実行入口は、必要な具象実装を組み立てるためにすべての境界を参照できる。
- MCP ツールはユースケースを参照できる。
- ユースケースは情報モデルと情報源ポートを参照できる。
- 情報源アダプターは、実装する情報源ポートと変換先の情報モデルを参照できる。

## 禁止する関係

- 情報モデルは、MCP、HTTP または e-Gov の型を参照しない。
- ユースケースは、トランスポートまたは情報源アダプターの具象型を参照しない。
- 情報源アダプターは、MCP ツールを参照しない。

## 確認

パッケージ依存を静的に検査し、禁止する関係がないことを確認する。
