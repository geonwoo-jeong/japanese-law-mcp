# SOT-ARCH-004: 情報源アダプター境界

- 状態: 有効

## 規定

情報源アダプターは、外部サービス固有のリクエスト、レスポンスおよびエラーをアダプター境界の外へ公開せず、共通の情報モデルへ変換する。

## 意味

外部 API の URL、操作名、フィールド名、列挙値およびエラー表現は、対応するアダプターの内部で扱う。

外部 API の変更は、その情報源のアダプターとインターフェース SOT で吸収する。

## 確認

外部 API のレスポンス型を、MCP ツールまたはユースケースの公開型が直接参照していないことを確認する。
