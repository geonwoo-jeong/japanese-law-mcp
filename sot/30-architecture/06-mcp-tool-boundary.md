# SOT-ARCH-006: MCP ツール境界

- 状態: 有効

## 規定

MCP ツール境界は、ツール入力の検証、MCP 型とユースケース型の変換、およびユースケース結果と MCP ツール結果の変換だけを扱う。

## 意味

ツール名、説明、入力スキーマ、出力スキーマおよび MCP のエラー表現はこの境界が所有する。

法令の検索条件、リビジョン選択または情報源固有のフィールド変換は、MCP ハンドラーへ実装しない。

## 確認

MCP ハンドラーを、情報源アダプターの具象型や e-Gov 固有型を使わずにテストできることを確認する。
