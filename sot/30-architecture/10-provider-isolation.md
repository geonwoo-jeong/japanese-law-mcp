# SOT-ARCH-010: プロバイダーの分離

- 状態: 有効

## 規定

外部サービスまたは互換性を持たない外部バージョンごとに独立したプロバイダーアダプターを置き、一つのプロバイダーの仕様変更が他のプロバイダーへ伝播しない依存境界を作る。

## 所有範囲

各プロバイダーアダプターは、次を自分の境界内に所有する。

- 接続先、操作名、認証方法およびリクエスト生成
- 外部リクエスト型、レスポンス型、列挙値およびエラーの解釈
- XML、JSON、CSV、HTML、PDF、GeoJSON、PBF、ZIP または XBRL のうち、そのプロバイダーが必要とする解析
- 文字コード、ページ方式、更新時点および取得制限の解釈
- 能力別モデルへの変換
- 公式仕様の版、確認日、fixture および契約テスト

同じ機関が提供するサービスでも、仕様、認証、更新周期または障害境界が異なる場合は別のアダプターとする。e-Gov 法令 API Version 1 と Version 2、国税庁法人番号 Web-API と適格請求書発行事業者 Web-API は、それぞれ分離する。

## 共有できる範囲

HTTP のタイムアウト、TLS、応答サイズ制限、安全な圧縮解除および文字コード変換のように、情報の意味を持たない技術的処理だけを共通基盤へ置ける。

外部フィールド名、CSS selector、外部列挙値、ページ規則、XBRL taxonomy の対応またはプロバイダー固有の再試行判断を、複数プロバイダーの共有実装へ置かない。

プロバイダーアダプターは、別のプロバイダーアダプターを import または呼び出さない。
