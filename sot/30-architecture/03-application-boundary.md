# SOT-ARCH-003: ユースケース境界

- 状態: 廃止
- 後継: [SOT-ARCH-020: 採用済みユースケース境界](20-adopted-use-case-boundary.md)

## 規定

ユースケース境界は、法令名検索、法令本文検索、法令本文取得および条文取得のシナリオを実行し、MCP の通信形式や特定の外部 API 形式には依存しない。

## 廃止理由

法令コアだけを列挙した境界を、選択型拡張パックの採用済みシナリオも含む `SOT-ARCH-020` に置き換える。

## 意味

この境界は、情報モデルを使って処理を組み立て、必要な情報源ポートを呼び出す。

MCP 固有のリクエスト型、HTTP リクエスト型および外部 API のレスポンス型をユースケースの判断へ持ち込まない。

## 確認

利用シナリオのテストを、実際の MCP 接続や外部ネットワークなしで実行できることを確認する。
