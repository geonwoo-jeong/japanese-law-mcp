# SOT-ARCH-014: 外部原文の一時処理

- 状態: 有効

## 規定

外部情報源から取得した HTML、PDF、画像、圧縮ファイル、地理データおよび XBRL は、現在のリクエストを完了するために必要な範囲だけで一時的かつ上限付きに処理し、リクエスト間で再利用または保存しない。

## 処理

取得した原文は、変換前に不変のバイト列として扱う。メモリーまたは一時ファイルを使用する場合は、応答サイズ、圧縮後と展開後の合計サイズ、展開ファイル数、解析深度および処理時間に上限を設け、リクエスト終了時に削除する。

処理対象の MIME type を能力ごとに許可リストで定め、`Content-Type` だけでなく先頭バイト、container signature または format magic で実体を確認する。宣言された形式と実体が一致しない場合は拒否する。

ZIP のパストラバーサルと過大展開、XML の外部エンティティ、HTML の実行可能な内容、PDF の埋込みファイルと過大な object、文字コード変換の失敗および gzip の過大展開を検出して拒否する。

HTML、PDF、XML および XBRL の解析はネットワークから分離して行い、外部参照、taxonomy、画像、stylesheet、font その他の副次的な資源を解析中に取得しない。必要な参照資源は、同じ能力が許可した origin から明示的な上限付き取得として先に取得する。

HTML 全体を既定の MCP テキスト結果として返さない。PDF、ZIP、PBF または XBRL の原文取得は、その表現を必要とする能力が別に採用された場合だけ許可する。

原文、認証情報、リクエスト値または展開したファイルを、エラー、ログ、診断、リクエスト間キャッシュまたは永続ストレージへ含めない。

## 確認

成功、解析失敗、キャンセル、タイムアウトおよび上限超過の各経路で、一時ファイルと参照がリクエスト終了後に残らないことを確認する。
