# SOT-ENG-015: txtar による CLI 契約テスト

- 状態: 有効

## 規定

外部から観測できる CLI の振る舞いは、対応する SOT ID を根拠として記載した txtar 形式の testscript で契約テストする。

## テスト境界

- 一つの txtar ファイルを、一つの独立して判定できる CLI シナリオとする。
- 各シナリオの先頭に、検証対象となる SOT ID を一つ以上記載する。
- 各シナリオを独立した一時作業ディレクトリと隔離した利用者設定ディレクトリで実行し、実行に必要な最小限の環境変数だけを明示的に与える。
- 引数、環境変数、標準入力、標準出力、標準エラー、生成ファイルおよびプロセス終了コードのうち、そのシナリオで観測対象となる結果を明示して検証する。
- 通常の CLI 契約テストは外部ネットワークへ接続せず、サーバー実行処理と外部情報源を決定的なテスト用実装へ置き換える。
- 期待値は SOT から導いた検証物として管理し、通常のテスト実行中に自動更新しない。

## 確認

CLI の有効なインターフェース SOT に基本動作、優先順位、境界値およびエラーの txtar シナリオが対応し、同じ入力を繰り返して同じ結果になることを確認する。
