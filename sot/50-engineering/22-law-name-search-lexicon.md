# SOT-ENG-022: 法令名検索辞書

- 状態: 有効

## 規定

法令名検索の正式名称、読みおよび別名は、出典と取得時点を検証できるバージョン付きの不変な辞書スナップショットとして管理する。

## データ

辞書は、e-Gov 法令 API Version 2 の `GET /laws` から取得した全法令の `law_id`、`law_revision_id`、`law_title`、`law_title_kana` および `abbrev` を公式スナップショットに保持する。補足辞書は、国立国会図書館の「日本法令索引」または所管府省の公式資料が特定の法令の通称若しくは略称として明示した語だけを、公式スナップショットと別のファイルへ保持する。

各スナップショットは、少なくとも次を持つ。

- schema version
- 情報源の識別子と URL
- UTC の取得日時または確認日
- 法令 ID と正式名称
- 別名ごとの種別
- 補足別名の場合は、その別名を確認できる個別資料の URL

国会会議録、検索結果の件数、一般のウェブページまたは編集距離だけを、別名採用の根拠にしない。取得時点以後の完全性を主張せず、更新時は同じ生成手順で公式スナップショット全体を置き換える。

## 読込み

起動時に schema version、必須文字列、URL、日時、法令 ID、重複および正規化後の衝突を検証する。公式情報源で同じ別名が複数の法令へ対応する事実は保持するが、自動解決では曖昧として扱う。補足辞書が既存の別名を別の法令へ対応させる場合は起動エラーとする。

読込み後の entry、別名、索引および利用側へ返す slice は変更できない形で扱う。Kagome の user dictionary は、重複を除いた正式名称と別名から起動時に生成し、同じ語の法令対応は法令名辞書の索引で判定する。

## 確認

実際に埋め込むスナップショットを製品と同じ loader で読み込み、件数、schema、出典、重複および衝突規則を検証する。壊れた JSON、未知の schema version、空の正式名称、無効な URL、重複 entry および補足辞書の不正な上書きを拒否する fixture を持つ。

代表的な正式名称、e-Gov 略称および補足略称が対応する法令 ID と正式名称へ解決し、情報源に存在する曖昧な略称が一つの法令へ縮約されないことを確認する。
