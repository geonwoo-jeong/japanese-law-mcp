# SOT-ENG-010: コンテキストと中断

- 状態: 有効

## 規定

外部 I/O またはリクエスト処理を行う Go 関数は `context.Context` を第一引数で受け取り、期限切れ、中断およびサーバー停止をすべての下位処理へ伝播する。

## 適用

- MCP ハンドラーが受け取ったコンテキストをユースケースと情報源アダプターへ渡す。
- HTTP リクエストは、受け取ったコンテキストから生成する。
- 下位処理で `context.Background()` または新しい独立したコンテキストへ置き換えない。
- サーバー停止時は受付を停止し、実行中の処理へ中断を通知してから終了する。

## 確認

クライアント中断、設定したタイムアウトおよびサーバー停止によって、実行中の情報源リクエストが終了することをテストする。
