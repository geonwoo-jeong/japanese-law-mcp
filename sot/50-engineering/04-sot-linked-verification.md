# SOT-ENG-004: SOT に結び付く検証

- 状態: 有効

## 規定

各 SOT は、その規定に適した検証方法と結び付け、検証物または確認記録から対象の SOT ID を追跡できるようにする。

## 検証方法

| SOT 領域 | 主な検証方法 |
|---|---|
| 製品 | SOT 間の参照と範囲のレビュー |
| 利用シナリオ | 基本フロー、分岐、完了条件のシナリオテスト |
| 情報モデル | シリアライズ、必須項目および制約の単体テスト |
| アーキテクチャ | パッケージ依存と境界の静的検査またはアーキテクチャテスト |
| インターフェース | 入力、出力、エラーおよび外部 API 変換の契約テスト |
| 開発 | 文書構造の静的検査またはレビュー |
| 提供とリリース | 実行方式、成果物およびリリース元の受入検査 |

自動テストに適さない規定は、レビュー手順または成果物の確認条件を検証方法とする。

同じ事実を検証側の独自仕様として再定義せず、対応する SOT ID を検証の根拠とする。

## 確認

変更した有効な SOT に適用可能な検証方法があり、その結果から SOT ID へ到達できることを確認する。
