# SOT-ENG-002: 境界型の分離

- 状態: 有効

## 規定

各パッケージ境界は自身が扱う型だけを公開し、MCP 型、利用目的の型、共通情報モデルおよび外部 API 型を同一の型として共有しない。

## 適用

- MCP のリクエスト型とレスポンス型は MCP 境界に置く。
- ユースケースの入力型と結果型は application 境界に置く。
- 法令を表す共通型は model 境界に置く。
- e-Gov 固有のリクエスト型とレスポンス型は source/egov 境界に置く。

境界を越えるときは、送り先が理解する型へ明示的に変換する。

## 確認

公開関数の引数と戻り値に、別の外部境界が所有する型が現れないことを確認する。
