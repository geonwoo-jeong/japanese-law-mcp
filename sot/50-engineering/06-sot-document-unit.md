# SOT-ENG-006: SOT 文書の単位

- 状態: 有効

## 規定

一つの SOT Markdown は、単独で採用、変更または廃止を判断できる最小の規定を一つだけ定義する。

## 文書形式

規則ファイルは、次の要素を一つずつ持つ。

- `# SOT-{領域}-{番号}: {名称}` 形式の見出し
- `状態` メタデータ
- `## 規定`
- 規定を具体化するために必要な構造、制約、分岐、確認方法および関連参照

一つのモデル、ツール、シナリオまたは設定インターフェースを構成する項目は、その規定を具体化する限り同じファイルに含める。

## 確認

各規則ファイルに一つの SOT ID と一つの `## 規定` があり、独立して採否を決められる複数の規定が混在していないことを確認する。
