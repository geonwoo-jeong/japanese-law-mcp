# SOT-ENG-007: SOT の識別子と番号

- 状態: 有効

## 規定

新しい規定には、領域内の次のファイル番号と、他の規定に再利用しない固有の SOT ID を割り当てる。

## 番号

- ディレクトリの十番単位の番号は、SOT を読む順序を示す。
- 規則ファイルの二桁番号は、領域内の表示順を示す。
- SOT ID は、他の SOT、コード、検証物、Wiki および ADR から参照する識別子とする。

## 変更

規定の主語、対象、義務および適用範囲を維持したまま明確化するときは、同じファイル番号と SOT ID を使用する。

規定の意味または適用範囲を置き換えるときは、新しいファイル番号と SOT ID を発行し、旧規定を廃止して後継 SOT ID を記録する。

廃止したファイル番号と SOT ID は、別の規定へ再利用しない。

## 確認

ファイル番号が領域内で重複せず、同じ SOT ID が複数の規則ファイルに存在しないことを確認する。
