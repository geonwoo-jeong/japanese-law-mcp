# SOT-PROD-009: 選択型法情報拡張パックの境界

- 状態: 有効

## 規定

法令コアの外で Japanese Law MCP の公開機能として採用を検討できる情報は、裁判例、立法過程、税務および労働の選択型法情報拡張パックに限定する。

## 採用を検討できる範囲

| 拡張パック | 対象にできる法情報 | 権威と完全性の境界 |
|---|---|---|
| 裁判例 | 裁判所が公表する裁判例 | 公式の公表資料として扱い、全ての裁判を収録した資料または一律に先例性を持つ資料とは扱わない |
| 立法過程 | 国立国会図書館の国会会議録、衆議院と参議院の議案、審議経過および公表文書 | 現行法令と区別し、会議、発言、議案および成立後の法令を同じ状態へ平坦化しない |
| 税務 | 国税庁の法令解釈通達その他の公式解釈資料、および国税不服審判所が公表する裁決 | 文書回答事例、質疑応答事例その他の事実関係に依存する資料は、個別 SOT が採用した場合だけ補助情報として扱う |
| 労働 | 厚生労働省が公表する所管法令、通知、通達その他の公式資料 | 公式データベースの収録範囲と官報優先の注意を保持し、JAISH を含む民間または委託先の情報源は、権利条件と補助採用理由を個別 SOT が定義した場合だけ補助情報として扱う |

各拡張パックは既定の法令コアへ暗黙に加えず、利用者が明示的に選択できる独立した機能境界とする。

拡張パックが `law.*` のように法令コアと同じ能力 ID を再利用する場合でも、その pack を選択していない無設定起動で既定の core route を変えてはならない。pack の有効化方法、同じ能力 ID を共有する route の選択方法、または pack-aware な設定構造を定義する後継 SOT を採用するまでは、当該 pack の provider を組込み既定値へ加えず、既存の core route と独立した公開機能または provider-specific capability としてだけ採用を検討する。

プロバイダーへ接続できること、共通識別子へ対応できること、または能力別ポートを実装できることは、拡張パックまたは公開 MCP ツールの採用を意味しない。

各拡張パックを公開する前に、`SOT-PROD-004` に従い、少なくとも利用目的、利用シナリオ、型付き情報モデル、情報源の公式仕様または取得方法、利用条件、収録範囲の注意、能力別インターフェース、公開 MCP インターフェースおよび検証方法を有効な個別 SOT で定義する。補助情報源は、公式情報源と区別できる権威区分、利用条件および採用理由も定義する。

## 対象外

次の情報は、この製品範囲へ含めない。

- 一般統計、法人情報、適格請求書発行事業者情報、不動産情報および企業開示情報
- 法情報の取得目的に直接対応しない広報、ニュース、一般的な FAQ、白書および解説資料
- 私企業の法令、裁判例または解説データベース
- 単一の確認可能な採用契約を持たない全国の条例の一括収集

対象外の情報を公開機能へ加える場合は、この規定を暗黙に拡張せず、製品範囲の変更として新しい後継 SOT を採用する。

## 確認

既定設定では法令コアだけが有効であること、および各拡張パックの公開面から必要な個別 SOT と権威区分へ到達できることを確認する。
