# SOT-PROD-017: 段階的に利用する簡潔な MCP 公開面

- 状態: 有効

## 規定

Japanese Law MCP は、利用できる法情報機能を失わずに MCP クライアントへ常時提示するツール数を抑え、必要な専門操作だけを発見して実行できる簡潔な公開面を既定とする。

## 利用者価値

MCP クライアントは、起動時にすべての専門操作の schema を受け取らなくても、日本語の統合照会を直ちに使用できる。決定的な入力を必要とする場合は、現在の拡張パック構成で利用可能な専門操作を検索し、選んだ一つを同じ契約で実行できる。

これにより、拡張パックを増やしても通常の tool 一覧とその schema が際限なく大きくなることを避ける。発見結果には一致した総数、返した数、省略した数および省略の有無を含め、候補が上限を超えたことを空結果または完全一覧と誤認させない。

## 互換利用

既存の専門ツール名を直接呼び出すクライアントの移行用に、設定ファイルで明示的に選ぶ完全公開方式を提供する。完全公開方式は既存の専門ツール契約を維持するが、新しい既定値にはしない。

公開方式は情報源、能力、provider route、結果、エラーまたは拡張パックの利用条件を変更しない。簡潔な公開面と完全公開面の正確なツール集合、設定および境界は `SOT-IF-077` を定義元とする。

## 対象外

- 未採用の能力または無効な拡張パックの操作を発見若しくは実行可能にすること
- 利用者が任意の provider、URL、内部関数または操作 schema を登録すること
- 発見結果を恒久保存し、別の起動構成でも利用可能であるとみなすこと
- MCP の resource、prompt、第二の endpoint または外部公開 transport を追加すること

## 確認

既定の公開ツール数が拡張パックの組合せで増えないこと、利用可能な全専門操作が発見と実行を通じて到達できること、無効な操作が到達不能であること、完全公開方式で既存の直接呼出しが維持されること、および省略件数を常に判別できることを契約テストで確認する。
