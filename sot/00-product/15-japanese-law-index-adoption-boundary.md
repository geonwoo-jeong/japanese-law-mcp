# SOT-PROD-015: 日本法令索引の採用保留境界

- 状態: 有効

## 規定

[日本法令索引](https://hourei.ndl.go.jp/help.html)は、2026年8月23日時点では
Japanese Law MCP の構造化 provider、capability、provider route または公開 MCP
tool として採用しない。

現在の製品で許可する利用は、次に限る。

- `SOT-ENG-022` に従う補足法令名辞書の根拠資料
- 利用者が人手で確認するための公式参照先 URL
- 将来の採用可否を判断するための一次資料調査

HTML 画面、未公開 endpoint、旧 API 連携データまたは観測した画面挙動を前提に、
機械取得 provider を実装しない。

## 保留理由

国立国会図書館の[API 一覧](https://www.ndl.go.jp/use/api)には、日本法令索引の専用
API が掲載されていない。国立国会図書館サーチの
[2024年1月の変更告知](https://ndlsearch.ndl.go.jp/news/renkei_20240105)では、
日本法令索引および日本法令索引〔明治前期編〕との API 連携終了が明示されている。

日本法令索引の[ヘルプ](https://hourei.ndl.go.jp/help.html)では、同サービスが法令と
法案の索引情報を提供し、法令データは基本的に 2月、5月、8月、11月に更新すると
示している。一方で、利用条件として、短時間の大量アクセスを避けること、
機械的アクセスでは多重 request を避け、各 request の間隔を数秒程度空けることが
求められている。さらに、法令データは外部機関である第一法規株式会社から提供を
受け、データベース自体の著作権は国立国会図書館に帰属すると示している。利用に
あたっては、[国立国会図書館ウェブサイトのコンテンツ利用規約](https://www.ndl.go.jp/sitepolicy/terms)
も確認が必要である。同規約が採用する
[公共データ利用規約（第1.0版）](https://www.digital.go.jp/resources/open_data/public_data_license_v1.0)
は、別の利用ルールが適用されるものを除き、出典表示を条件として複製、送信、
翻訳、変形等および商用利用を認めている。一方で、第三者の権利、外部データベース等
との API 連携で取得したコンテンツの利用条件、および個別法令による制約は利用者が
確認すべきものとしている。したがって、一般的な転載条件だけを根拠に構造化 provider
の採用可否を決めない。

この状態では、`SOT-PROD-007` が採用条件とする、文書化された公式取得方法、
安定した機械取得契約、再利用条件の境界、および構造変更検知を伴う provider 契約を
満たせない。

## 現時点で採用しない範囲

次は採用しない。

- 日本法令索引の検索結果 HTML を解析する provider
- ブラウザ挙動に依存する headless scraping
- 国立国会図書館サーチの旧連携 ID、旧 identifier または過去 dump の再利用
- 全件収集、定期クロール、バックグラウンド更新、稼働監視
- 日本法令索引だけを根拠にした法令本文、法案本文または審議経過本文の生成

日本法令索引の索引情報は、法令本文、法案本文、会議録本文または法的結論と同一視
しない。

## 将来の採用条件

将来、日本法令索引を構造化 provider として採用するには、少なくとも次を同じ変更
単位で満たす。

1. 公式に公開された機械取得手段が存在し、現在の利用条件を一次資料で確認できる。
2. 法令索引、法案索引、法令沿革、被改正法令、審議経過のうち、どの資源をどの
   型付き capability で扱うかを新しい SOT で分離して定義できる。
3. 安定した識別子、継続取得、欠落、更新単位および日付の意味を interface SOT に
   定義できる。
4. `SOT-PROD-007` に従い、短時間大量アクセスの回避、多重 request の禁止、
   数秒程度の間隔という公開条件に反しない取得方式を、リクエスト内だけで実装できる。
5. 利用シナリオ、情報モデル、source mapping、built-in adoption および検証方法を
   pack 単位で採用してから実装へ進める。

## 確認

次を確認する。

- この SOT から API 一覧、連携終了告知、日本法令索引ヘルプおよび利用規約へ到達
  できること
- 現在の実装に `hourei.ndl.go.jp` を source provider とする binding、route または
  公開 tool が存在しないこと
- 補足法令名辞書の根拠として使う場合でも、`SOT-ENG-022` の範囲を超えて
  provider 採用へ拡張しないこと
