# SOT-DEL-005: 実行経路

- 状態: 有効

## 規定

各公式提供形態は、MCP プロセスの実行場所とリクエストが通過する環境を利用者が判別できる形で説明する。

## 経路

| 提供形態 | MCP の実行場所 | 法情報リクエストの経路 |
|---|---|---|
| macOS・Windows 向け実行ファイル | 利用者の環境 | MCP クライアント → ローカルプロセス → e-Gov |
| パッケージマネージャー向け配布物 | 利用者の環境 | MCP クライアント → ローカルプロセス → e-Gov |
| クライアント設定またはプラグイン | 利用者の環境 | MCP クライアント → 設定が起動したローカルプロセス → e-Gov |
| 自己運用コンテナ | 運用者の環境 | MCP クライアント → 運用者の HTTP プロセス → e-Gov |
| 管理された MCP エンドポイント | プロジェクトが管理する環境 | MCP クライアント → 管理された HTTP プロセス → e-Gov |

クライアント設定またはプラグインを、管理されたリモートエンドポイントを経由する方式として説明しない。

HTTP を利用する形態では、HTTP プロセスを運用する主体がリクエストを処理中のメモリーで扱うことを明示する。いずれの経路も `SOT-ARCH-005` の一時性を適用する。

## 確認

各インストール手順と接続例に、実行場所、トランスポートおよび接続先が記載され、実際の設定と一致することを確認する。
