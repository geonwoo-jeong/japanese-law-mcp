# SOT-DEL-003: 公式配布物

- 状態: 有効

## 規定

Japanese Law MCP は、ローカル実行、MCP クライアントへの導入、コンテナによる自己運用および管理されたリモート接続に必要な配布形態を、同じリリースのソース状態から公式に提供する。

## 配布形態

| 形態 | 主な用途 |
|---|---|
| macOS・Windows 向け実行ファイル | ランタイムを別途導入しないローカル実行 |
| パッケージマネージャー向け配布物 | バージョン指定によるインストールと更新 |
| MCP クライアント向け設定またはプラグイン | stdio 接続の導入 |
| OCI コンテナイメージ | Streamable HTTP の自己運用 |
| 管理された MCP エンドポイント | インストール不要のリモート接続 |

各配布形態は、同じ MCP ツール、情報モデルおよびエラー契約を提供する。配布方法によって法情報の意味を変えない。

## 確認

各公式配布物について、バージョン、生成元、利用する転送方式および対応するリリースを確認できることを検証する。
