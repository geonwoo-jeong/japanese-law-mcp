# SOT-DEL-011: ローカル公式配布物

- 状態: 有効

## 規定

Japanese Law MCP の公式配布物は、利用者のローカル環境で同じ実行ファイルを起動する形に限定し、プロジェクトが運用するリモートサービスを提供しない。

## 配布形態

| 形態 | 主な用途 |
|---|---|
| macOS・Windows 向け実行ファイル | ランタイムを別途導入しないローカル実行 |
| パッケージマネージャー向け配布物 | 同じローカル実行ファイルのインストールと更新 |
| MCP クライアント向け設定またはプラグイン | 利用者環境の実行ファイルを stdio で起動する導入 |

パッケージマネージャー、設定またはプラグインが、法情報リクエストをプロジェクト管理の中継先へ送信しない。

OCI コンテナイメージ、管理された MCP エンドポイント、SaaS、プロジェクト管理の proxy およびリモート実行環境は、公式配布物に含めない。

各配布形態は、同じ MCP ツール、情報モデル、エラー契約および実行ファイル版を使用する。配布方法によって法情報の意味を変えない。

## 確認

各公式配布物について、実行ファイルの版、生成元、checksum およびローカル実行経路を確認する。配布設定と通信試験で、MCP クライアントから外部情報源までの間にプロジェクト管理の中継先がないことを検証する。
