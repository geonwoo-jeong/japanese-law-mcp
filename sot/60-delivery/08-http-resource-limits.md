# SOT-DEL-008: HTTP リソース制限

- 状態: 有効

## 規定

Streamable HTTP は、一つの利用主体による過大な入力または実行中の呼び出しが他の利用者と e-Gov への接続を圧迫しないよう、リクエストサイズと同時実行数を制限する。

## 制限

- HTTP リクエスト本文は 1 MiB 以下とする。
- 一つの認可主体について、同時に実行するツール呼び出しは 4 件以下とする。
- 認可を使用しないループバック接続では、接続元アドレスを利用主体として扱う。
- 同時実行数の判定に使う状態は、その時点で実行中のリクエストだけとし、完了、失敗または中断と同時に解放する。過去の呼び出し回数、時刻、利用主体の履歴または集計を、リクエスト間で保存しない。

リクエスト本文の上限超過には `413 Payload Too Large`、同時実行数の上限超過には `429 Too Many Requests` を返し、ツールを実行しない。

## 確認

本文サイズの上限直前と超過時、および同一利用主体の同時実行数の上限直前と超過時をテストし、拒否したリクエストが MCP ツールまたは e-Gov 呼び出しへ到達しないことを確認する。加えて、完了済みリクエストの履歴または集計を保持しないことを確認する。
