# SOT-DEL-008: HTTP リソース制限

- 状態: 有効

## 規定

Streamable HTTP は、一つの利用主体による過大な入力または呼び出しが他の利用者と e-Gov への接続を圧迫しないよう、リクエストサイズ、呼び出し頻度および同時実行数を制限する。

## 制限

- HTTP リクエスト本文は 1 MiB 以下とする。
- 一つの認可主体について、ツール呼び出しは 1 分間に 60 回以下とする。
- 一つの認可主体について、同時に実行するツール呼び出しは 4 件以下とする。
- 認可を使用しないループバック接続では、接続元アドレスを利用主体として扱う。

リクエスト本文の上限超過には `413 Payload Too Large`、頻度の上限超過には `429 Too Many Requests` と `Retry-After`、同時実行数の上限超過には `429 Too Many Requests` を返し、ツールを実行しない。

## 確認

各上限の直前と超過時をテストし、拒否したリクエストが MCP ツールまたは e-Gov 呼び出しへ到達しないことを確認する。
