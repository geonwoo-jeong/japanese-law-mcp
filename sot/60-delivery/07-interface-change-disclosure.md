# SOT-DEL-007: インターフェース変更の告知

- 状態: 有効

## 規定

公式リリースで MCP ツール、入力、出力、エラーまたは設定を互換性なく変更する場合は、変更対象、利用者への影響および置き換える利用方法をリリース情報に明記する。

## 適用

互換性の維持を変更の採否条件にはしない。削除、名称変更、型変更、意味変更または既定値変更を行った場合に、変更前と変更後を識別できる情報を示す。

代替手段がない場合は、その事実を明記し、存在しない移行手順を示さない。

## 確認

公開インターフェースの差分とリリース情報を比較し、互換性のない変更が漏れなく記載されていることを確認する。
