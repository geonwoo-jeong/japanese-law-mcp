# SOT-SCN-017: 専門操作を発見して実行する

- 状態: 有効

## 規定

利用者は、現在の起動構成で利用可能な専門操作を名前または説明から検索し、返された正確な schema に従って選んだ一つを実行できる。

## 開始条件

Japanese Law MCP が簡潔な公開方式で起動し、利用者が日本語の統合照会ではなく決定的な専門操作を必要としている。

## 基本フロー

1. MCP クライアントが `discover_legal_tools` に任意の検索語と返却上限を送る。
2. Japanese Law MCP が、有効な法令コアと拡張パックから利用できる専門操作だけを検索し、名前順の先頭候補を返す。
3. 応答が一致した総数、返した数、省略した数および省略の有無を示す。各候補は名前、説明、正確な入力 schema および出力 schema を持つ。
4. MCP クライアントが候補の `name` を `execute_legal_tool.toolName` に指定し、候補の入力 schema に適合する JSON object を `arguments` として送る。
5. Japanese Law MCP が同じ起動構成の allowlist から操作を選び、専門操作の結果またはエラーを変更せず返す。

## 分岐

- 検索条件に一致する操作がない場合は、件数をすべて `0` とした成功結果を返す。
- 一致数が返却上限を超える場合は、先頭候補だけを返し、省略数と `truncated: true` を明示する。
- 発見入力または実行入力が schema、型、byte 上限若しくは重複 key の制約に違反する場合は、専門操作または外部情報源を呼び出す前に入力エラーを返す。
- 指定した操作が存在しない場合と、対応する拡張パックが無効な場合は、区別できない同じ入力エラーを返す。
- 専門操作が成功、空結果または公開可能なエラーを返した場合は、直接呼出しと同じ結果を返す。

## 完了条件

利用者は、発見応答の省略状態を判別し、返された schema に適合する入力で一つの読取り専用専門操作を実行し、その操作固有の結果またはエラーを確認できる。
