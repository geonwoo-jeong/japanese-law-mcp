# SOT-SCN-005: 更新日から法令更新一覧を取得する

- 状態: 有効

## 規定

利用者は、一つの暦日を指定し、その日に公式情報源の更新一覧へ掲載された法令を、正確な総件数および各法令の出典とともに取得できる。

## 開始条件

利用者が実在する `YYYY-MM-DD` 形式の暦日を指定している。

## 基本フロー

1. MCP クライアントが更新一覧の対象日を送信する。
2. Japanese Law MCP が `law.update.list@1` の primary route を通じて公式情報源の一日分の完全な一覧を取得する。
3. 取得した各結果を `LawUpdate` として公開用の一覧へ投影する。
4. 対象日、正確な総件数および更新情報の配列を返す。

## 分岐

- 該当する法令がない場合は、成功した空の一覧として返す。
- 日付を解釈できない場合は、入力エラーとして返す。
- 日付が選択したプロバイダーの公式な提供範囲外である場合は、未対応の検索条件として返す。
- 情報源を利用できない場合または情報源の応答が契約を満たさない場合は、原因を保持した情報源エラーとして返す。
- 情報源が示していない省略可能な値を推測して結果へ加えない。

## 完了条件

返された対象日、総件数および各更新情報の対象日が一致し、各項目から公式情報源を確認できる。
