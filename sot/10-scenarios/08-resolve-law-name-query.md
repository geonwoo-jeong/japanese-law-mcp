# SOT-SCN-008: 法令名検索語を解決する

- 状態: 廃止
- 後継: [SOT-SCN-011: 解決済み法令を検索結果で優先する](11-prioritize-resolved-law-search-result.md)

## 規定

原検索が非空の場合に、解決済み法令を同じ page 内で優先できないため、
本規定を `SOT-SCN-011` に置き換えた。

以下は廃止時点の履歴であり、現行の利用シナリオには適用しない。

利用者は、正式な法令名を知らない場合でも、出典を確認できる略称、表記揺れを含む名称、法令名を含む自然文または軽微な誤記によって法令を検索できる。

## シナリオ

1. 利用者が `search_laws` に検索語を渡す。
2. システムは検証済みの入力を変更せず、選択済みの法令検索プロバイダーで最初に検索する。
3. 最初の検索が正常な空結果である場合だけ、法令名検索用の辞書と日本語解析を使って検索語を解決する。
4. 一つの法令へ安全に解決できた場合は、その法令の正式名称で同じプロバイダーを検索する。
5. 複数の法令が候補になる場合、短すぎる語または信頼できる候補がない場合は推測せず、最初の空結果を返す。
6. 情報源または内部処理のエラーは、別の検索語による再検索で隠さず利用者へ返す。

## 対象

- e-Gov 法令 API Version 2 で確認した法令名と略称
- 出典と確認日を記録した補足略称
- Unicode の互換表記、空白および句読点による表記揺れ
- 法令名または略称を一つだけ含む自然文
- 一意に判定できる軽微な挿入、削除、置換または隣接文字の転置

意味が近いだけの語を同じ法令として扱わない。意味上の同義語または通称は、対応する法令と出典を辞書で確認できる場合だけ使用する。

## 確認

正式名称、公式略称、補足略称、全角と半角、句読点を含む自然文および一文字の誤記を fixture とし、一意な場合だけ同じ法令へ解決することを確認する。複数の法令名を含む文、衝突する略称、短い誤記および同率の候補では検索語を自動変更しないことを確認する。
