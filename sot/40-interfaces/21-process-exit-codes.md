# SOT-IF-021: プロセス終了コード

- 状態: 有効

## 規定

公式実行ファイルは、終了結果を次のプロセス終了コードで表す。

| 終了コード | 意味 |
|---:|---|
| `0` | サーバーの正常終了、正常な中断、またはヘルプとバージョンの正常な出力 |
| `1` | サーバーの起動または実行中に発生した、継続できない実行エラー |
| `2` | コマンド、位置引数、フラグまたは起動時設定のエラー |

MCP リクエストの処理結果と外部情報源のエラーは `SOT-IF-027` と `SOT-IF-007` に従って MCP の応答として返し、それだけを理由にプロセスを終了しない。

## 確認

正常終了、各補助コマンド、無効なコマンドライン入力、無効な設定およびサーバー実行エラーについて、標準エラーと終了コードを契約テストで確認する。
