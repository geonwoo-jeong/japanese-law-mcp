## 現在の起動面

統合法情報照会をまだ実装していない現時点では、引数を指定しないルートコマンドは stdio MCP サーバーを起動する。無設定時の公開ツールは `search_laws`、`get_law`、`get_article`、`search_law_content` および `list_law_updates` の五つである。`streamable-http` を指定した場合は、検証済みの loopback 待受先で `/mcp` を提供し、stdio と同じ公開ツール集合を使用する。

現時点の無設定時は e-Gov 法令 API Version 2 の四つと、e-Gov 法令 API Version 1 の `law.update.list@1` の、合計五つの組込み primary route を起動時に構成する。`judicial-cases` が有効な場合は `courts-hanrei-html` の二つも内部 registry と route へ構成し、`search_judicial_cases` と `get_judicial_case` を一つの集合として追加して七つの MCP ツールを公開する。統合法情報照会の実装完了後に採用する公開構成は `SOT-IF-040` の六ツールと八ツールであり、現在の五ツールと七ツールはその実装差分である。片方の binding、route、service または tool だけでは transport を開始しない。利用者は設定ファイルで provider の有効化、能力別 primary route および rollback override を指定でき、無効な組合せは transport の開始前に終了コード `2` で拒否する。組込み provider は provider-specific setting と credential slot を持たず、非空の `settings` と `credentialEnvRefs` は受け付けない。
